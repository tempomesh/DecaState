THE WASTE NOBODY MEASURES

You already paid to understand your codebase. You're paying for it again.

Every restart, crash, or new agent throws away the model's understanding and rebuilds it from scratch. Not because your code changed — because the state was disposable.

Read repo · minutes → Process dies ✕ → Reads it ALL again → New agent? All again

The same expensive work, on a loop, all day.

THE FIX

Save the model's working memory — the real KV cache, not a chat log.

DecaState serializes the model's actual inference state to disk with integrity and fingerprint guards. Kill the process, reboot the machine, then wake the state in a brand-new process and continue exactly where it stopped — with zero of the original context re-processed.

$ decastate understand . # read the repo ONCE → native state
$ decastate checkpoint repo-ready repo-understood
$ decastate fork reviewer # new agent from that understanding, ~15 ms
# … kill the process, reboot …
$ decastate rollback repo-ready repo-understood ✓ byte-exact, no re-prefill
