# Changelog

## 0.1.0 — Investor MVP

- Native MLX state workspace lifecycle.
- Separate-process save/wake verification.
- Immutable checkpoint/rollback with lineage and fingerprint checks.
- Physical-copy fork correctness.
- Atomic state writes, integrity hashes, and per-state locks.
- Real repository coding-agent demo.
- Local production verification command.

Not included in 0.1.0: distributed deployment, cloud state storage, COW savings, runtime migration, model migration, and state-aware routing.
